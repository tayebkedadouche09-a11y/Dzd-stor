# DZD Store 🇩🇿

متجر بسيط لبيع المنتجات الرقمية، مبني كبداية خفيفة بدون قاعدة بيانات أو دفع إلكتروني.

## الموجود حالياً
- واجهة عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.
- أقسام للمنتجات.
- بطاقات منتجات وأسعار بالدينار الجزائري.
- سلة مشتريات تعمل بـ LocalStorage.
- تصميم جاهز للتطوير لاحقاً.

## تشغيل محلي
افتح `index.html` مباشرة في المتصفح، أو استعمل أي static server.

## الخطوات القادمة
1. صفحة تفاصيل المنتج.
2. تسجيل الدخول وحساب العميل.
3. قاعدة بيانات للمنتجات والطلبات.
4. الدفع الإلكتروني CIB / EDAHABIA.
5. تحميل الملفات بعد نجاح الدفع بشكل آمن.
6. لوحة تحكم لإضافة المنتجات وإدارة الطلبات.
7. SEO ونسخ عربية/فرنسية/إنجليزية.
